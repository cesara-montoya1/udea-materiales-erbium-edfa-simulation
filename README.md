# Erbium-Doped Fiber (EDFA) Population Dynamics Simulation

> [!NOTE]
> **Archived Academic Project**  
> This repository is a read-only historical archive of coursework developed for academic evaluation.

## Overview
Numerical modeling and population dynamics simulation of Erbium-Doped Fiber Amplifiers (EDFA), developed for the **Materiales en Ingeniería** course at **Universidad de Antioquia**.

## Simulation Models
* **Two-Level Rate Equations**: Numerical solving of steady-state and time-dependent population inversions ($N_1, N_2$) under 980 nm and 1480 nm optical pumping.
* **Spectral Analysis**: Emission and absorption cross-section modeling around the 1550 nm C-band telecommunication window.
* **Evolution Tracking**: Rate-equation convergence, population sweep visualizations, and gain saturation behavior.

## Technologies
* Python & SciPy (ODE solvers)
* Matplotlib (High-resolution comparative plots for population dynamics and emission spectra)
